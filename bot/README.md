# Бот-постер курса

Публикует курс в Telegram-группу и держит последнее сообщение в актуальном
состоянии. Работает на том же сервере, что и сайт (`alipayfast.ru`).

## Что изменилось относительно старого бота

| Было | Стало |
|---|---|
| Считал курс сам: ЦБ + своя таблица надбавок (`1.04 / 0.94 / 0.84 / 0.83`) | Берёт готовый ранжир из API сайта — цифры совпадают с сайтом и мини-аппом |
| Пост в 10:00 Владивосток | Пост в **16:00** Владивосток (`POST_HOUR`) |
| Надбавка зашита в код | Надбавка из `/admin/exchange`; бот её подхватывает |
| При изменении курса — ничего | Правит **последнее** сообщение (новое не публикует) |
| Telegram напрямую | Telegram через `TELEGRAM_PROXY_URL` (VLESS → локальный SOCKS5/HTTP) |
| `text.txt` с цитатами | Без изменений: тот же файл, тот же цикл |

Курс больше не считается внутри бота: единственный источник истины —
`GET /api/exchange-rate` сайта. Поэтому «разъезда» курсов быть не может.

## Как работает синхронизация (п.4)

1. Ежедневно в 16:00 бот берёт курс с сайта и публикует **новое** сообщение
   с очередной цитатой.
2. Каждые `SYNC_INTERVAL_SEC` (по умолчанию 300 с) бот заново читает ранжир
   с сайта и сравнивает текст с тем, что в последнем сообщении.
3. Если текст изменился (оператор поменял надбавку в `/admin/exchange` или
   обновился курс ЦБ) — бот **редактирует последнее сообщение**, а не пишет
   новое. Цитата в нём сохраняется.

Связка «последнее сообщение» хранится в SQLite (`last_post`), поэтому после
перезапуска бот продолжает править то же сообщение.

## Установка

```bash
cd /opt/alipayfast
git pull --ff-only

cd bot
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен бота (см. предупреждение про polling ниже);
- `POST_CHAT_ID` — ID группы/канала (например, `-1001234567890`);
- `ADMIN_USER_ID` — ваш Telegram ID;
- `TELEGRAM_PROXY_URL` — локальный порт VLESS-клиента;
- `SITE_API_URL` — по умолчанию `http://127.0.0.1:3000/api/exchange-rate`.

Скопируйте со старого сервера:

```bash
# цитаты
scp old-server:/path/to/text.txt /opt/alipayfast/bot/text.txt
# состояние (номер цитаты) — чтобы продолжить последовательность
scp old-server:/path/to/subscribers.db /opt/alipayfast/bot/subscribers.db
```

Если `subscribers.db` не переносить, бот начнёт цитаты с первой.

## Telegram через VLESS (п.1)

VLESS/XTTP сам не является прокси для приложений. На сервере должен быть
запущен локальный клиент (xray/sing-box), который слушает `127.0.0.1`:

```env
TELEGRAM_PROXY_URL=socks5://127.0.0.1:10808
# или
TELEGRAM_PROXY_URL=http://127.0.0.1:10809
```

Подробнее и пример конфига xray — `docs/telegram-proxy.md`.

Проверка, что прокси работает:

```bash
curl --socks5 127.0.0.1:10808 https://api.telegram.org/
```

Запросы к API сайта идут **без** прокси (localhost), прокси нужен только для
Telegram.

## Запуск

### systemd

```bash
sudo cp bot/deploy/alipayfast-poster.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now alipayfast-poster
sudo journalctl -u alipayfast-poster -f
```

### pm2 (как сайт)

```bash
cd /opt/alipayfast/bot
pm2 start poster_bot.py --name alipayfast-poster --interpreter /opt/alipayfast/bot/.venv/bin/python
pm2 save
pm2 logs alipayfast-poster
```

## Ручное управление

Публикация и синхронизация доступны локально (только `127.0.0.1`):

```bash
# принудительно опубликовать сейчас (следующая цитата)
curl -X POST "http://127.0.0.1:8081/post_today?token=$CONTROL_TOKEN"

# принудительно привести последнее сообщение к курсу сайта
curl -X POST "http://127.0.0.1:8081/sync?token=$CONTROL_TOKEN"
```

`CONTROL_TOKEN` — из `.env`. Если он пустой, HTTP-управление выключено.

### Команды в Telegram (опционально)

`POSTER_ENABLE_POLLING=1` включает `/post_today` и `/sync` в самом боте.

> ⚠️ Включайте только для **отдельного** бота. Если `BOT_TOKEN` совпадает с
> ботом сайта или мини-аппа (у них стоит вебхук на новом сервере), polling
> конфликтует с вебхуком. Бот это проверяет и отказывается включать polling,
> если токены совпадают — в логе будет ошибка.

## Формат text.txt

Одна цитата на строку, нумерация в начале убирается автоматически:

```
1. Терпение и труд всё перетрут.
2. Дорогу осилит идущий.
```

Цитаты идут по кругу; номер хранится в `subscribers.db` (`wisdom_state`).

## Если что-то не так

| Симптом | Причина / решение |
|---|---|
| `BOT_TOKEN не задан` | нет `bot/.env` или пустой токен |
| `Файл цитат не найден` | положите `text.txt` рядом с ботом или задайте `WISDOM_FILE` |
| В логе «Сайт на запасном курсе» | ЦБ недоступен сайту; бот подождёт, чтобы не публиковать неверные цифры |
| «API сайта вернул HTTP…» | сайт не запущен на `127.0.0.1:3000` или изменился `SITE_API_URL` |
| Пост не появляется | проверьте `POST_CHAT_ID` (бот должен быть в группе/админом канала) |
| Telegram таймаутит | не настроен `TELEGRAM_PROXY_URL` или не запущен VLESS-клиент |
| «сообщение недоступно» | последнее сообщение удалили — привязка сбрасывается, следующий пост создаст новое |
