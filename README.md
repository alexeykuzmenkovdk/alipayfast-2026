# AlipayFast 2026

Новый сайт AlipayFast (пополнение Alipay юанями, Владивосток) — новый дизайн из `project.zip`,
собранный в Next.js 14 поверх рабочих механик курса из предыдущего сайта (`alexeykuzmenkovdk/Ali2026`).

## Что здесь есть

- **Новый дизайн** — весь лендинг из прототипа: шапка с бегущим курсом, hero с хунбао, калькулятор,
  график курса, «Почему мы», «Как это работает», площадки, услуги, Telegram-блок, офис, отзывы, FAQ,
  контакты, модалка заявки, мобильная панель. Плюс страница **«Полезные материалы»**.
- **Механики курса** — перенесены из предыдущего сайта:
  - базовый курс **CNY/RUB с сайта ЦБ РФ** (`app/api/exchange-rate`),
  - **динамическая надбавка** по сумме в юанях (`lib/exchange-config.ts` → `DYNAMIC_MARKUP`),
  - **ручной курс** администратора, отключающий надбавки (`/admin/exchange`),
  - **история курса по дням** для графика (`lib/exchange-history.ts`, `data/exchange-history.json`),
  - уведомления об изменениях курса и о новых заявках в Telegram.

## Как формируется курс

1. Сервер берёт официальный курс юаня с ЦБ РФ (`XML_daily.asp`). При ошибке используется `FALLBACK_RATE`.
2. К базовому курсу прибавляется надбавка по уровню суммы:

   | Сумма пополнения | Надбавка к курсу ЦБ |
   |---|---|
   | до 500 ¥ | +0.96 ₽ |
   | 500 – 2 000 ¥ | +0.84 ₽ |
   | 2 000 – 6 000 ¥ | +0.80 ₽ |
   | от 6 000 ¥ | +0.73 ₽ |

   Уровни задаются в `lib/exchange-config.ts`. Калькулятор пересчитывает курс в обе стороны (₽ ⇄ ¥).
3. Если в `/admin/exchange` включён ручной курс — надбавки не применяются, используется заданное значение.
4. Каждый ответ `/api/exchange-rate` пишет базовый курс дня в `data/exchange-history.json`; график
   строит «наш курс» как `базовый курс + надбавка выбранного уровня`.

## Запуск

```bash
npm install
cp .env.example .env   # заполнить токены Telegram и пароль админки
npm run dev            # http://localhost:3000
```

Прод:

```bash
npm run build && npm start
```

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_SITE_BOT_TOKEN` | токен бота для уведомлений о заявках и смене курса |
| `TELEGRAM_SITE_CHAT_ID` | чат/канал, куда приходят уведомления |
| `ADMIN_PASSWORD` | пароль входа в `/admin/exchange` |
| `NEXT_PUBLIC_SITE_URL` | домен для `sitemap.xml` (необязательно) |

Без токенов Telegram заявка и смена курса работают в демо-режиме (без реальной отправки).

## Маршруты

| Путь | Описание |
|---|---|
| `/` | лендинг |
| `/materials` | полезные материалы |
| `/admin/exchange` | настройки курса (надбавка / ручной курс) |
| `/api/exchange-rate` | текущий курс и уровни |
| `/api/exchange-history` | история курса по дням |
| `/api/send-telegram` | приём заявки с сайта и отправка в Telegram |
| `/api/admin/auth` | вход в админку |
| `/api/admin/exchange-settings` | чтение/запись настроек курса |

## Замечания

- `data/exchange-history.json` засеян правдоподобным рядом на ~180 дней, чтобы график сразу
  отрисовывался; дальше файл наполняется реальными значениями с ЦБ РФ.
- Дизайн-прототип (React + статичный CSS) перенесён в компоненты `components/site/*` с сохранением
  исходных классов и разметки; глобальные стили — `app/globals.css` (бывший `styles.css`).
- Хранение настроек курса и истории — в памяти/на диске (как в предыдущем сайте). Для продакшена
  за бесплатным/эфемерным FS (Vercel) стоит подключить БД или внешнее хранилище.
